# Интернет-магазин Megano (Дипломный проект Skillbox)

Проект представляет собой полнофункциональный интернет-магазин, разработанный на фреймворке Django с использованием Django REST Framework для API и Vue.js (через пакет `diploma-frontend`) для фронтенда.

## 🚀 Технологии

*   **Backend**: Python 3.11, Django 4.2+, Django REST Framework
*   **База данных**: SQLite (по умолчанию, легко заменяется на PostgreSQL через `.env`)
*   **Асинхронные задачи**: Celery + Redis
*   **Frontend**: Vue.js 3 (подключается как сторонний пакет `diploma-frontend`)
*   **Управление зависимостями**: pip, venv

## 📦 Установка и запуск

Следуйте этим шагам, чтобы развернуть проект на локальной машине.

### 1. Клонирование репозитория

```bash
git clone https://github.com/mvgum/python_django_diploma.git
cd python_django_diploma
2. Создание и активация виртуального окружения
Для Windows:

bash
python -m venv venv
venv\Scripts\activate
Для macOS/Linux:

bash
python3 -m venv venv
source venv/bin/activate
3. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10 или выше.

bash
pip install -r requirements.txt
4. Установка фронтенд-пакета
Фронтенд поставляется как отдельный Python-пакет. Он находится в папке python_django_diploma-master/diploma-frontend. Установите его в режиме редактирования (editable), чтобы изменения в шаблонах применялись сразу:

bash
pip install -e python_django_diploma-master/diploma-frontend
5. Настройка переменных окружения (.env)
В корне проекта создайте файл .env на основе примера .env.example (или скопируйте содержимое ниже):

env
DEBUG=True
SECRET_KEY=ваш_секретный_ключ_сгенерируйте_его
ALLOWED_HOSTS=127.0.0.1,localhost
DATABASE_URL=sqlite:///db.sqlite3
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/0
Как сгенерировать SECRET_KEY?
Выполните в терминале:

bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
Скопируйте результат в .env.

6. Применение миграций
Создайте таблицы в базе данных и примените начальные данные:

bash
python manage.py migrate
7. Создание суперпользователя (Администратора)
Для доступа в панель управления Django Admin:

bash
python manage.py createsuperuser
Введите логин, email и пароль.

8. Запуск Redis и Celery (Асинхронная оплата)
Для работы оплаты через очередь задач (Celery) необходимо запустить брокер сообщений Redis и сам воркер Celery. Вы можете выбрать любой из двух способов:

Вариант А: Через Docker (Рекомендуется для проверяющих)
Если у вас установлен Docker Desktop, выполните в корне проекта:

bash
docker-compose up -d --build
Это автоматически поднимет Redis и Celery в фоне. Вам не нужно запускать Celery вручную.

Вариант Б: Локальный запуск (Для Windows без Docker)
Установите и запустите Memurai (порт 6379).

В отдельном терминале (с активированным venv) выполните:

bash
celery -A config worker -l info -P solo
(Флаг -P solo обязателен для Windows).

9. Запуск сервера разработки
Вернитесь в первый терминал (где активировано окружение) и запустите Django:

bash
python manage.py runserver
Сайт будет доступен по адресу: http://127.0.0.1:8000/
Админка: http://127.0.0.1:8000/admin/

🧪 Тестирование функционала
Каталог: Перейдите в раздел "Каталог". Попробуйте поиск по названию, фильтр по цене и сортировку.

Корзина: Добавьте товары в корзину, измените их количество.

Оформление заказа: Нажмите "Оформить заказ", заполните данные, выберите доставку и оплату.

Оплата: На странице оплаты введите четный номер карты (например, 12345678), не заканчивающийся на 0. Оплата должна пройти успешно (обрабатывается через Celery). Если ввести нечетный номер, оплата завершится ошибкой.

Личный кабинет: Проверьте историю заказов, отредактируйте профиль (ФИО, телефон, аватар).

📂 Структура проекта
config/ — основные настройки Django, маршрутизация, настройки Celery.

catalog/ — приложение каталога (модели категорий, товаров, характеристик, отзывов).

users/ — кастомная модель пользователя, регистрация, авторизация, профиль.

cart/ — логика корзины.

orders/ — оформление заказов, оплата, история.

python_django_diploma-master/ — исходники фронтенд-пакета (Vue.js).

.env — переменные окружения (не коммитится в Git).

🛠 Возможные проблемы
Ошибка ModuleNotFoundError: No module named 'frontend': Убедитесь, что вы выполнили шаг 4 (установка фронтенд-пакета).

Celery не подключается к Redis: Проверьте, запущен ли Memurai/Redis (шаг 8).

Стили не загружаются: Выполните команду python manage.py collectstatic (опционально, для продакшена).
